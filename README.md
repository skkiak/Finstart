# FinStart — Financial Literacy Academy 💰📘

**FinStart** is an online platform that helps users build financial knowledge step by step.  
The project features a structured course of lessons, progress tracking, and basic budgeting tools to support users on their journey to financial freedom.

## 🔗 Live Demo
🌐 Website: https://skkiak.github.io/Finstart/

## 🧠 Project Overview
FinStart is designed for beginners who want to learn the fundamentals of personal finance. The platform includes:
- a sequence of **19 detailed lessons** covering key financial topics
- **user registration and login**
- **personal dashboard** with progress tracker
- **budget planner** for income and expenses
- achievement badges to encourage learning

This project demonstrates skills in interactive UI, educational design, and user state management.

## ✨ Key Features
- 📚 **Financial lessons** — structured learning path for financial literacy.
- 📝 **User registration and login** — basic user authentication interface.
- 💡 **Dashboard & achievements** — visualize progress and earned trophies.
- 💸 **Budget planner & FinScore** — manage income, expenses, and track a custom financial score.

## 🛠 Technologies Used
This project was built using:
- HTML  
- CSS  
- JavaScript  

## 🧪 Purpose & Learning Outcomes
FinStart was created as an **educational tool** to help users:
- understand budgeting and money management
- improve financial decision‑making skills
- build a habit of tracking financial goals

## 📁 Example Use Cases
- personal budget planning practice  
- interactive online course for beginner financial learners  
- demonstration project for frontend UI skills
